- A hosted new farm and every joining guest started with an empty pack: both now get the new-game kit (`giveStartKit`).
- The guest night report heading used the stale farm copy; it now uses the day in the night news.
- Two guests were both "Guest": `Room.join` now makes names unique (Guest, Guest 2).
- The host's farm now shows "Others can join at ip:port". The host port is random, not 8787.
- A guest's Action opened only beds, so the guest shop and bin screens were unreachable: it now opens any screen a guest may use.
- Lobby layout (host text over the wallet button, keyboard past its panel) and tool names in the bin ("Hoe", not "tool:hoe").
