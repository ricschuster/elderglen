All look like a stale note and not a code fault, except wheat, which is the
owner's call. Two rows rest on a comment or on the priority list and are marked.

1. Aim reach. Note 07 ("Desktop mouse") says 2 tiles. The code has
   `AIM_REACH = 1` in `src/core/aim.ts` (tool reach 1, #547).
2. Cast energy. Note 07 ("Fishing") says a cast costs no energy. The code
   charges 8, less 0.1 per fishing level (`CAST_ENERGY` and
   `CAST_ENERGY_PER_LEVEL` in `src/core/fishing.ts`).
3. Rod and level gates. Note 07 says the Reed Pole hooks common fish only and
   rare fish need fishing level 5. The comment on `bite` in
   `src/core/fishing.ts` says every rod hooks any fish and no level gates rare
   ones (note 21). Not traced: the pool filter itself was not read.
4. Wheat. Note 07 lists it with the crops (summer and fall, 4 days, 10g, 25g).
   There is no wheat in `src/content/crops.json` or anywhere in `src/`.
5. Hardwood stand-in. Note 07 ("Eating", the stable paragraph) still says the
   carpenter sells Hardwood at 200g. The priority list says #639 removed it.
   Not confirmed in the shop code.
6. Crop quality. Note 07 says Stardew's fertiliser term is left out.
   `src/core/quality.ts` includes the soil term.
7. Tool upgrades. Note 07 says the hoe and can only, four tiers, gold only in
   the shop. `src/core/upgrades.ts` has four tools, five tiers, 5 bars a step
   and a 2 day wait.
8. Mines. "The mines, first part" says floors 1 to 10 only, floor 10 has no
   ladder and the camp chest is only on floor 10, and "Mines and combat" is
   headed "draft, not built". `src/content/mine-bands.json` has 120 floors and
   camp ore gifts per metal (copper 3, iron 3, gold 2).
9. Geodes. Note 07 gives one weight table (stone 30, coal 15 and so on).
   `src/content/geodes.json` has per-band pools and four geode kinds (note 69).
