# Farm layout draft (note 55)

A rough block-out for the owner to check, not the real map. Open
`farm-draft.tmj` in Tiled. The tiles are flat colour swatches (`tiles.png`).
Paint on the `ground` layer (the house, greenhouse and cave are on `objects`), move the objects on `markers`, and save over the
file. `farm-draft-preview.png` is a picture of the same map with a 10 tile grid.

On Ubuntu: `sudo apt install tiled`.
