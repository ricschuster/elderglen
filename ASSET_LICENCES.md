# Asset licences

Almost every picture in the game is drawn in code at start up, in
`src/scenes/art.ts` and its companions `art-people.ts`, `art-animals.ts`,
`art-creatures.ts` and `art-crops.ts`. It is original work for this project and covered by the
content licence in `LICENSE-CONTENT.md` (CC BY-NC 4.0). The one exception is the hand-drawn witch test
(see the table).

| Asset                                      | Source                        | Licence      |
| ------------------------------------------ | ----------------------------- | ------------ |
| Tiles (grass, path, water, soil and so on) | `src/scenes/art.ts`           | CC BY-NC 4.0 |
| Player and villager sprites                | `src/scenes/art-people.ts`    | CC BY-NC 4.0 |
| Farm animals and the horse                 | `src/scenes/art-animals.ts`   | CC BY-NC 4.0 |
| Mine creatures                             | `src/scenes/art-creatures.ts` | CC BY-NC 4.0 |
| Crop growth stages and seed packets        | `src/scenes/art-crops.ts`     | CC BY-NC 4.0 |
| Forage pictures                            | `src/scenes/art.ts`           | CC BY-NC 4.0 |
| Tool icons                                 | `src/scenes/art.ts`           | CC BY-NC 4.0 |
| Tilled and watered soil                    | `src/scenes/art.ts`           | CC BY-NC 4.0 |
| Menu screen frame                          | `src/scenes/art.ts`           | CC BY-NC 4.0 |
| UI buttons and toolbar slots               | Plain shapes in scenes        | CC BY-NC 4.0 |

Nothing is copied or traced from Stardew Valley or any other game (see
`docs/decisions/0002-stardew-valley-inspired.md`). When a third party asset is
added, list it here with its source and licence before merging.
